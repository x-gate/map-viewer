# NPC 圖層與 npc.txt 相容性

日期：2026-09-17。僅修改 `map-viewer`；沿用 xglib 既有 WASM 契約，不新增 API。`cgmsv` 與 `CGoriginmood` 只供唯讀分析，未納入原始設定或素材。

## 格式依據

本機 `cgmsv/gmsv/data/npc.txt` 可用 GB18030／GBK 解碼，包含註解與空白行。記錄以 25 個 Tab 分隔欄位組成，必須保留空欄，不能按任意空白切割。以下位置為零起算，是對私人模擬伺服器資料的相容性判讀，不是官方格式保證。

| 欄位   | 本工具用途     | 依據與待確認事項                                                                                                                                            |
| ------ | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0、1   | 類型、名稱     | `npctype.txt` 類型表及 `lua参考/NL.lua` 的 CreateArgNpc 參數描述相符；保留原始名稱，不自動轉換簡繁體。                                                      |
| 3      | NPC 編號       | 觀察到可辨別記錄的數值；另保留來源行號，同號記錄不合併。                                                                                                    |
| 7、8   | 地圖類型、樓層 | NL.CreateArgNpc 區分 Map 與 Floor；本機第 7 欄均為 0，第 8 欄可與 client 地圖編號比對。本工具採 `Assets/map/<類型>/…/<樓層>.dat` 映射；其他伺服器仍需確認。 |
| 9–16   | 四組座標       | 固定 NPC 四組相同；不同時可能代表生成／活動區域，未執行伺服器確認。本工具保留全部數值並標示多組座標，暫以第一組定位。                                       |
| 19、20 | 面向、造型     | 對照 NL.CreateArgNpc 的 Dir/Image；例如 1011 的 `(19,13)` 造型 14002 可在 GraphicInfo 的 map_id 找到。空欄以未指定標示並保留記錄。                          |
| 24     | 類型參數       | NL.lua 說明最後一組為類型參數；本工具不保存、執行或顯示其內容。其他欄位不推定為出現條件。                                                                   |

只顯示檔案中配置的 NPC，未模擬日期、任務、生成機率、隨機位置、移動、腳本或即時出現狀態。造型 0、未指定造型、缺少資源或解碼失敗者顯示原創位置標記與名稱。超出地圖尺寸的記錄列入診斷。

## 圖像與動畫

NPC 設定中可獨立選取 Graphic 和 Anime 資源，CGP 沿用目前檢視器設定。只在同目錄配對相同尾碼的 Info／資料檔；Graphic 和 Anime 的版本尾碼不必相同，不自動跨來源補圖。支援 Assets/bin 子目錄，舊版使用者需重新選取遊戲根目錄以掃描 Anime。

造型先比對 AnimeInfo 的 ID；不存在時以 GraphicInfo.map_id 查靜態造型。動畫的 frame.graphic_id 透過 GraphicInfo 第一欄 ID 查找，不能當成索引列或 map_id。各索引同號採末列，沿用目前相容策略。

依 `cgmsv/lua参考/CONST.lua` 的 `CHAR_ACTSTAND = 0` 選站立動作，優先相同面向；缺少相同面向時暫用可用站立方向並明示警告。無站立動作時保留位置標記。AnimeInfo 為 12 bytes、動作 header 為 12／20 bytes、影格為 10 bytes；逐動作判斷 extended sentinel，計算實際已用範圍後交給 `anime_build_from_bytes`，不把索引間隙當作動畫。

播放沿用 rsc-manager 已記錄的 CGTool 相容語意：週期除以影格數為間隔，異常週期使用 100 ms；鏡射繞 GraphicInfo 定位點，不另加 frame.off_x/off_y。extended 動作可使用所選 Graphic 中 map_id 等於動畫 ID 的隱藏調色盤，優先於影格色表；否則使用影格內嵌色表或 CGP。NPC 色彩索引 0 透明。這些是相容性選擇，尚未全量比對原作。

NPC 使用格位中心＋GraphicInfo 偏移，和物件一起按投影深度排序，可獨立開關。只在畫面內存在多影格 NPC 時排程更新；隱藏或移出畫面時停止。可見範圍取全部影格聯集，避免單一影格離開視窗時停住動畫。

## 載入與上限

開啟地圖後點「NPC 設定」另選 npc.txt，不要求它位於遊戲根目錄，也不由後端讀取工作區路徑。自動先用嚴格 UTF-8，再用 GB18030；可指定 UTF-8、GB18030／GBK、Big5。檔案參照只在當次頁面使用，重新整理需再選一次。切換地圖按類型／樓層篩選；切換來源重新解碼；選另一個遊戲根目錄或移除資料會清空 NPC 檔案參照。

獨立 Worker 解析；檔案最多 8 MiB，每圖最多 2,000 筆、256 種造型／方向組合。站立動作最多 512 影格／128 張獨立圖像、32 MiB RGBA；每圖 NPC 圖像最多 128 MiB。超出部分明示診斷。地圖／設定變更會終止舊 Worker，清除舊紋理及過期結果，不改寫地圖或 NPC 檔案。

## 驗證

- 原創資料＋真實 WASM：空欄、註解、行號、重複 ID、GBK／Big5、地圖類型／範圍、子目錄配對、靜態及動畫引用、方向回退、末列、鏡射、隱藏色表與截斷。
- Chrome：造型實際像素、動畫影格變化、獨立開關、無圖診斷、來源切換、定位、切換地圖、移除資料及原有試放回歸。
- 本機唯讀：10,164 筆 NPC，其中 9 筆空面向／造型欄有診斷。1011 的 10 筆均可用 Graphic_66 解碼；Anime_4 的 100000／面向 6 使用末列 2375，為 4 影格、3 張圖像、250 ms 間隔。僅輸出統計，未匯出原版像素或複製設定。

未執行模擬伺服器，也未驗證全部 NPC、Safari／Firefox 或動態任務狀態。測試 npc.txt、圖像、動畫皆為自行建立的合成資料。

# 跨資源集候選與逐格試放

日期：2026-09-13。變更僅涉及 `map-viewer`，沿用既有 xglib WASM 契約與建置版本。

## 比對規則與範圍

點選地圖格位後，預設搜尋非零物件層，否則搜尋地表層；使用者可切換圖層。以原始地圖該層的 `u16` ID，比對所有已辨識且具有 GraphicInfo / Graphic 配對的來源中 `map_id` 完全相同的列。ID 0 表示空層，不搜尋；圖像自身的 `id`、索引列號與 `map_id` 不可互換。

候選保留「GraphicInfo 相對路徑＋索引列」身分，同號多列全部列出。這是人工比對規則，不代表已證實原作的資源覆蓋順序、地形用途或 meta 語意。列表包含來源、配對圖像檔、尺寸、偏移與位址，方便逐筆辨認。

索引在獨立 Worker 中分塊讀取並建立一次；每頁最多 12 筆，只解碼該頁縮圖。無效索引會保留列與錯誤說明；strict 解碼失敗的候選無法試放。整個來源無法讀取時顯示警告，不把部分搜尋結果當作全量成功。

預覽與試放都使用 xglib 的 strict CGP 解碼入口、所選 CGP 與原有垂直翻轉慣例。具有內嵌調色盤的格式由 xglib 判讀。縮圖完成後不保留整張 RGBA；實際試放時重新讀取該來源及索引列。

## 試放生命週期

試放記錄以「格位＋圖層」區分，不修改原始地圖陣列。相同 ID 的其他格位不受影響；同一格的地表及物件可獨立試放。候選使用自己的偏移、尺寸與來源紋理，保留原有物件深度排序。

每張地圖最多 256 處試放，兩個圖層分別計算；試放紋理預算為 128 MiB，同一候選多次使用共用紋理。還原後釋放不再使用的紋理。可還原單一格層或清除全部；切換地圖、重新套用設定、重新選資料夾與頁面重載會清除。關閉面板保留目前試放。搜尋及試放回應使用世代與點選順序排除過期結果。

沒有地圖匯出、儲存或遊戲根目錄寫入功能；不新增 xglib 公開介面或遷移格式。

## 驗證

- 合成資源＋真實 WASM：全來源搜尋、重複列身分、圖像 ID 與 map_id 區別、分頁、不同來源／列的像素、損毀索引及 payload、空 ID、無結果、重新初始化。另驗證搜尋本身不讀取 Graphic payload。
- Chrome：候選縮圖、分頁與錯誤列；試放後畫面像素改變、還原後像素相同；同號其他格位隔離、兩圖層獨立、清除全部與切換地圖清除。使用原創合成資源，不產生原版遊戲圖像截圖。
- 唯讀本機樣本：使用新 `CandidateLibrary` 掃描 7 組來源。`1011.dat` 的 `(23, 5)` 為地表 1167／物件 2，`(21, 5)` 為地表 1168／物件 2。物件 ID 2 找到 75 筆：`Graphic_Joy_EX_151` 74 筆、`Graphic_Joy_EX2_1` 1 筆，75 筆皆 strict 解碼成功，無來源警告；只輸出統計，不匯出像素。

75 筆候選可解碼不等於已確認原作應擺放哪一筆。本次未進行全量地圖的原作畫面比對，也未新增 Safari / Firefox 驗證。
